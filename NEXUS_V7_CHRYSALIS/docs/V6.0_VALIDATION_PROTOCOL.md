# Protocole de Validation NEXUS V6.0 - Pré-Évolution

**Auteur**: Yann Abadie
**Date**: 2025-11-21
**Objectif**: Valider le fonctionnement correct de NEXUS_V6.0 avant le premier cycle d'évolution (V6.0 → V6.1)
**Criticité**: BLOQUANT - Aucune évolution ne doit être lancée sans validation complète du parent

---

## Philosophie du Protocole

**Pourquoi valider avant d'évoluer ?**

1. **Baseline claire** - Impossible de mesurer l'amélioration d'un enfant si on ne connaît pas les capacités exactes du parent
2. **Éviter la propagation de bugs** - Un parent défectueux créera des enfants défectueux
3. **Benchmarks fiables** - Les ASI scores ne valent rien si le système de mesure est cassé
4. **Intégrité KERNEL** - Vérifier que les 5 lois sont respectées avant toute mutation

**Critère de succès global**: 100% des tests doivent passer. Un seul échec = STOP évolution.

### T1.3 - LINEAGE.json Cohérence
**Objectif**: Vérifier la cohérence de l'arbre phylogénétique

```python
cd C:\Code\NEXUS\20_NEXUS\NEXUS_V7_CHRYSALIS
python -c "
import sys
sys.path.insert(0, '..')
from NEXUS_V7_CHRYSALIS.core.evolution import lineage

lin = lineage.load_lineage()

# Vérifications
errors = []

# 1. Parent actuel existe
if lin['current_parent']['id'] not in lin['lineage_tree']:
    errors.append('Parent actuel absent du lineage_tree')

# 2. Générations cohérentes
current_gen = lin['current_parent']['generation']
tree_gen = lin['lineage_tree'][lin['current_parent']['id']]['generation']
if current_gen != tree_gen:
    errors.append(f'Incohérence génération: {current_gen} vs {tree_gen}')

# 3. Compteurs logiques
if lin['evolution_stats']['total_generations'] != current_gen:
    errors.append('Compteur total_generations incohérent')

# 4. Stagnation counter valide
if not (0 <= lin['evolution_stats']['stagnation_counter'] <= 3):
    errors.append('Stagnation counter invalide')

if errors:
    print('❌ LINEAGE.json: ERREURS DÉTECTÉES')
    for e in errors:
        print(f'   - {e}')
    sys.exit(1)
else:
    print('✅ LINEAGE.json: Cohérent')
"
```

**Critère de succès**: 0 erreur détectée
