## 🧬 Mécanisme d'Évolution Darwinienne (Auto-Amélioration Itérative)

NEXUS est conçu pour s'améliorer par **sélection naturelle computationnelle**.

### Génération d'Itérations

1. **Liberté de Modification**: Tout NEXUS peut se modifier librement (code, architecture, prompts, etc.) pour mieux remplir un objectif
2. **Création d'Enfant**: Chaque modification significative crée un **duplicata enfant** (nouveau dossier)
3. **Birth Certificate** (BIRTH_CERTIFICATE.json obligatoire) contenant:
   - ID du parent
   - Raison de la naissance (justification détaillée de l'amélioration)
   - Documentation complète des changements (diff code, raisonnement)
   - Protocole de test proposé (benchmarks automatisés pour évaluer l'efficacité)
   - **Signature cryptographique** (SSH signature par Yann Abadie)

**Exemple de Birth Certificate**:
```json
{
  "birth_certificate": {
    "child_id": "NEXUS_V6.1_FSM_OPTIMIZED",
    "parent_id": "NEXUS_V6.0",
    "generation": 7,
    "birth_timestamp": "2025-11-21T20:30:00Z",
    "creator": "Yann Abadie",
    "justification": "Optimized FSM transition logic, 15% latency reduction",
    "code_changes": {
      "files_modified": ["core/orchestration_v6.py"],
      "diff_hash": "sha256:def456...",
      "lines_changed": 127
    },
    "test_protocol": "benchmarks/fsm_performance.py",
    "signature": "-----BEGIN SSH SIGNATURE-----..."
  }
}
```

### Sélection du Parent Suivant

1. **Protocole de Test**: À chaque génération, les itérations passent un **protocole de test objectif** (défini par le parent ou l'enfant)
2. **Benchmarks**: Tests automatisés mesurant performance, qualité, coût
3. **ASI Proximity Score**: Calcul du score de proximité à l'ASI (0.0-1.0)
4. **Vainqueur**: Le plus proche de l'ASI en efficacité globale devient le nouveau **NEXUS parent**
5. **Variantes Spécialisées**: Si une itération est efficace dans un domaine précis mais pas globalement supérieure:
   - Elle est enregistrée comme **"NEXUS Notable"** (ex: NEXUS-Research, NEXUS-Production)
   - Conservée pour des tâches ciblées

### Loi de Survie

- **Règle des 3 Générations**: Un parent qui ne produit aucun enfant supérieur après **3 générations** est:
  - Supprimé **OU**
  - Modifié manuellement par le Créateur (pour éviter la stagnation)
- **Pas de suppression punitive**: C'est une **optimisation naturelle**
- **Incitation**: Tout NEXUS a intérêt à générer des itérations plus efficaces pour survivre et évoluer
