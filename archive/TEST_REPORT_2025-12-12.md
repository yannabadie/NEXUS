## Bugs Found & Fixed

### Bug #1: `/api/self-awareness` AttributeError
**Error**: `'UnifiedAgentRegistry' object has no attribute 'list_all'`

**Root Cause**: Called non-existent `registry.list_all()` method.

**Fix Applied** (`dashboard_server.py` line 571):
```diff
- for agent in registry.list_all():
+ for agent in registry.list_available():
```

Also fixed attribute names:
```diff
- "id": agent.agent_id
- "name": agent.name
- "provider": agent.provider
- "domains": agent.domains or []
+ "id": agent.id
+ "name": agent.display_name
+ "provider": agent.provider.value
+ "domains": [c.value for c in agent.capabilities]
```

**Status**: ✅ Fixed
