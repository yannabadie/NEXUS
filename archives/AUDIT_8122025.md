### 7.4 Recommandation Architecturale Majeure

**Probleme Central**: NEXUS utilise des wrappers CLI pour invoquer les LLMs.

**Solution**: Migrer vers les SDKs officiels:
```python
# Actuel (fragile)
subprocess.run(["gemini", "-p", prompt, "--resume", uuid])

# Recommande (robuste)
from google import generativeai as genai
response = genai.GenerativeModel('gemini-pro').generate_content(prompt)

from anthropic import Anthropic
response = Anthropic().messages.create(...)
```

**Impact**:
- Latence: 20-120s → 2-10s
- Fiabilite: 60% → 95%+
- Controle: Timeouts, retry, streaming natif
